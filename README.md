# Runnel

> Trace the work. Stop only what the evidence proves safe.

Runnel is a macOS-first, local-only CLI for developers running many AI coding
workflows. The default command groups resource use by workflow. Its separate recovery
path stays locked unless a versioned detector proves an exact target set and protects
active work by construction.

Status: engineering-plan stage. No public release exists yet.

See [the engineering plan](docs/ENGINEERING_PLAN.md) for the build and verification
contract.
